# Tania Yunita — Frontend Developer Portfolio

Personal portfolio website showcasing my professional experience, selected projects, frontend skills, and approach to building responsive and maintainable web applications.

## Overview

This portfolio was built as a practical frontend project to showcase how I approach modern web development — from translating UI designs into responsive interfaces to organizing reusable components, handling application state, and considering accessibility and user experience.

The project also serves as a continuous learning space for improving my frontend engineering skills and exploring better approaches to building maintainable web applications.
## Live Demo

🌐 https://taniayunita.vercel.app


## Features

- Responsive design across mobile, tablet, and desktop
- Light and dark theme
- English and Indonesian language support

- Professional experience timeline
- Featured project showcase
- Project case study pages
